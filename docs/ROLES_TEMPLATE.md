# Таблица ролей и индивидуального вклада

Заполнить перед защитой конкретными фамилиями и commit/файлами.

| Участник | Основная зона | Конкретно сделано | Файлы / commits | Что должен уметь объяснить |
|---|---|---|---|---|
| Student 1 | Data / EDA | Dataset, EDA, split, leakage checks | `data/`, notebook sections 1–4 | features, class imbalance, train/val/test |
| Student 2 | Modeling | Baseline, RF, XGBoost, metrics | `train.py`, notebook sections 5–7 | algorithms, hyperparameters, threshold, metrics |
| Student 3 | Explainability / analysis | SHAP, error analysis, limitations | `results/`, notebook sections 8–10 | SHAP, false positives/negatives, responsible AI |
| Student 4 | Engineering / demo | FastAPI, Docker, reproducibility | `app.py`, `Dockerfile`, `README.md` | API request flow, model loading, deployment limits |

Если проект индивидуальный — оставить одну строку и перечислить весь вклад.
